2. DeepPavlov Topics Dataset

This is the specialized dataset containing 4.2 million conversational samples spread cleanly across 33 distinct topics like Politics, Health & Medicine, and Finance. [1] (https://deeppavlov.ai/datasets/topics)
• Official Landing Page: Read the full dataset specifications on the DeepPavlov Topics Dataset Page.
• Hugging Face Repository: Find the active open-source files and code wrappers in the DeepPavlov Dataset Hub. [1] (https://deeppavlov.ai/datasets/topics)

3. Yahoo! Answers Topic Classification Dataset

Ideal for capturing user intent phrasing, this dataset splits 1.4 million instances into 10 key topic buckets, which directly feature Health, Business & Finance, and Politics & Government. [1] (https://huggingface.co/datasets/yassiracharki/Yahoo_Answers_10_categories_for_NLP), [2] (https://arxiv.org/pdf/2307.15293)
• Hugging Face Dataset Card: Cleanly download or stream parquet splits straight from the Yahoo Answers 10 Categories Dataset.
• Sentence-Transformers Variant: For semantic embedding fine-tuning, you can leverage the Sentence-Transformers Yahoo Answers Dataset. [1] (https://huggingface.co/datasets/sentence-transformers/yahoo-answers), [2] (https://huggingface.co/datasets/yassiracharki/Yahoo_Answers_10_categories_for_NLP)
