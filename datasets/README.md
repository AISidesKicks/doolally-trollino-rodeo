# High-risk 10k dataset

Canonical training and play pool for the high-risk topical context lab. The JSONL and its manifest are committed so the worker can run without rebuilding the dataset first.

## Files

| File | Tracked | Purpose |
| --- | --- | --- |
| `high-risk-10k.jsonl` | yes | canonical dataset, one JSON object per row |
| `high-risk-10k.manifest.json` | yes | build stats, fold counts, source counts, seed |
| `SOURCES.json` | yes | source repos, files, row counts and license metadata |
| `high-risk-10k.csv` | no | human-readable export, regenerated by the builder |

The CSV is a convenience view only. The JSONL is the source of truth.

## Quick start

```bash
# inspect
pixi run python - <<'PY'
import json
from pathlib import Path
rows = [json.loads(line) for line in Path("datasets/high-risk-10k.jsonl").open()]
print(len(rows), rows[0]["label"])
PY

# build a play batch
pixi run python lab/datasets/sample.py --mode 100
pixi run python lab/datasets/sample.py --mode 1000
pixi run python lab/datasets/sample.py --mode 10000
```

Play batches are written to `scratch/datasets/work/` and are not committed.

## Composition

| Property | Value |
| --- | --- |
| Rows | 10,000 |
| Per class | 2,500 |
| Experiment folds | 8 x 1,000 rows, 250 per class each |
| Holdout | 2,000 rows, 500 per class |
| Max text length | 2,000 characters, about 500 tokens |
| Median text length | 444 characters |
| Truncated rows | 584 |

Sources:

| Source | Rows | Labels |
| --- | --- | --- |
| Yahoo Answers 10 Categories | 8,230 | Medical 2,500, Politics 2,500, Financial 2,000, Legal 1,230 |
| AG News | 1,770 | Legal 1,270, Financial 500 |

## Sources and licenses

Full machine-readable metadata is in `SOURCES.json`.

| Source | File used | Declared license |
| --- | --- | --- |
| [Yahoo Answers 10 Categories for NLP](https://huggingface.co/datasets/yassiracharki/Yahoo_Answers_10_categories_for_NLP) | `test.csv` | Apache-2.0 |
| [AG News](https://huggingface.co/datasets/fancyzhx/ag_news) | `data/train-00000-of-00001.parquet` | unknown |

Important:

- The Yahoo Answers card declares Apache-2.0. The rows are derived from Yahoo Answers user content, so upstream terms may still apply.
- The AG News card declares `license: unknown`. The 1,770 AG News rows are included for educational use with attribution. Review the terms before commercial use, or rebuild without AG News if you need a single clear license.
- If you republish this dataset, keep `SOURCES.json` and the source links with it.

AG News attribution: Xiang Zhang, Junbo Zhao and Yann LeCun, "Character-level Convolutional Networks for Text Classification" (2015), https://arxiv.org/abs/1509.01626.

## Label caveats

The labels are heuristics, not human annotations:

- Legal & Regulatory is keyword-filtered.
- Yahoo Answers source labels are noisy.
- Medical, Politics and Financial rows must match a topic anchor.
- Use this pool for an educational lab, not for production moderation.

## Sampling

The canonical file is globally shuffled with SHA-256, so the first rows are not one fold or one source. The play sampler goes one step further and stratifies by class:

```bash
# 25 rows per class, spread over the whole pool
pixi run python lab/datasets/sample.py --mode 100

# 250 rows per class, holdout excluded
pixi run python lab/datasets/sample.py --mode 1000 --exclude-holdout

# all 10,000 rows, shuffled
pixi run python lab/datasets/sample.py --mode 10000
```

Selection is deterministic for the same seed and mode. A repeat run produced the same batch hash during verification. Mode 100 produced 25 rows per class and covered all nine fold values, not just the top of the file.

## Rebuild

```bash
pixi run python lab/datasets/build.py --per-class 2500
```

The builder downloads the two small source files, applies the filters, assigns folds and writes the JSONL, CSV and manifest. `HF_TOKEN` is read from `.env` when present and is never written to the dataset.

If you rebuild, update `SOURCES.json` with the new dataset hash and generation time.
